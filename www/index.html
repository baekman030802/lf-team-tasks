알림

마감 오늘·내일, 마감을 넘길 것 같은 일을 하루 한 번 알려줍니다. 웹 페이지에서는 이 화면이 열려 있을 때만 알림이 옵니다. 갤럭시 앱(APK)에서는 앱이 꺼져 있어도 정해진 시각에 알림이 오고, 홈 화면 위젯도 쓸 수 있습니다.

비서 대기 · 호출어 → Claude

켜두면 상단에 '비서 대기 중' 알림이 떠 있습니다. 호출어를 말하면 '띵' 소리 후 Claude가 뜹니다 (8초 뒤부터 다시 들음). 폰을 다시 켜면 여기서 다시 켜주세요. 앱 설정 → 배터리를 '제한 없음'으로 두면 중간에 꺼지지 않습니다.

폰 ↔ 컴퓨터 동기화

폰과 컴퓨터에 같은 동기화 코드를 넣으면 저장할 때마다 자동으로 맞춰집니다. 처음엔 데이터가 있는 기기에서 [새 코드 만들기] → [연결]을 먼저 하세요.
